#caixa-simulator-portugol

This is my first practical project focused on programming logic, developed during my studies in Systems Analysis and Development.

Features:
- Balance inquiry.
- Cash withdrawal.
- Validation of amounts and checks for insufficient funds.
- Balance updates following a withdrawal.
- Interactive menu with an option to exit.
  
Technologies and concepts:
- Portugol / VisuAlg.
- Variables and operators.
- Conditional structures.
- Loops (repetition structures).
